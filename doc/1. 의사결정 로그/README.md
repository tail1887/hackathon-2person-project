# 의사결정 로그

이 폴더는 프로젝트의 확정된 제품·개발·디자인·MVP 범위 결정을 날짜별로 관리하는 주 기준 위치다. 제품 방향의 설명은 [기획서](../0_커플들이_집착하는_AI_심판이_되었다_기획서.md)를 따르며, 기획서의 의사결정 로그 절은 이 폴더를 안내하는 링크로만 유지한다.

## 기록 규칙

- 중요한 방향 결정은 관련 구현이나 문서 수정이 끝나기 전에 해당 날짜의 `YYYY-MM-DD_의사결정_로그.md`에 기록한다.
- 같은 날짜의 결정은 기존 파일에 추가한다. 새 날짜 파일은 결정이 있는 날에만 만든다.
- 각 결정은 `DYYYY-MM-DD-NN · 구분 · 상태` 제목과 `결정`, `이유/근거`, `영향 범위` 불릿으로 기록한다. `NN`은 해당 날짜 파일에서 `01`부터 생성 순서대로 증가한다.
- 기존 결정을 바꾸면 기존 행의 상태를 `폐기`로 바꾸고, 새 결정은 별도 행으로 남긴다.
- 제안·검증 결과·스크럼 안건은 확정 전까지 이 로그의 결정 블록으로 기록하지 않는다.

## 작성 양식

```md
### D2026-09-19-01 · 개발 방향 · 확정

- 결정:
- 이유/근거:
- 영향 범위:
```
