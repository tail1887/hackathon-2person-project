# M4 페이즈 2 협상 수락 UI 검증보고서 v1

> 상태: 보완 필요 · 2026-09-21

## 검증 범위

무승부 협상에서 응답자가 받은 조건을 선택·수락하는 화면을 목업과 현재 React UI·CSS로 대조했다.

## 수행한 확인과 결과

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 제안 조건·책임 주체·수락/카운터/계속 대국 행동 | 기능 연결됨 | `NegotiationPanel`의 수락·카운터오퍼·계속 대국 명령 연결 |
| 목업의 조건 선택 행 | 실패 | 목업은 체크박스/라디오와 조건 텍스트가 한 줄에 있고 책임 주체는 그 아래에 보인다. 현재 화면은 체크박스가 카드 상단 중앙에 분리된다. |
| 선택 상태의 시각적 의미 | 미흡 | 전역 `input` 규칙이 체크박스·라디오에도 적용돼 선택 입력이 넓은 입력 칸처럼 계산되며, 조건명과 선택 조작의 연결이 약하다. |

## P10 · 무승부 제안 수락 조건의 선택 조작 분리

- 문제: `.selection-condition` 내부의 radio/checkbox가 전역 텍스트 입력 너비·패딩을 상속해, 조건 텍스트와 떨어져 표시된다.
- 영향: 응답자는 무엇을 선택하는지 빠르게 파악하기 어렵고, 목업 직접 이관 원칙을 충족하지 못한다.
- 권장 보완: 수락 조건 행을 `선택 입력 + 조건명`의 수평 행과 `책임 주체` 보조 정보로 분리한다. 선택 입력은 고정 크기·자동 너비·패딩 0으로 재설정하고, 선택된 카드는 테두리·배경으로 표시한다.
- 재검증: 단일 선택과 복수 선택 각각에서 입력·조건명·책임 주체가 목업처럼 정렬되고, 선택/해제 및 수락 활성화가 정상인지 수동 확인한다.
