## 미검증 항목과 남은 위험

- 로컬 Supabase `status`는 Docker 소켓에 연결할 수 없어 실패했다. Docker Desktop을 시작한 뒤 `supabase start`와 마이그레이션 적용을 검증해야 한다.
- Supabase 원격 프로젝트 연결, 카카오·구글 OAuth 콜백, 이메일 로그인, Realtime Broadcast 권한, RLS와 Edge Function 비밀값은 아직 실제 계정·환경이 없으므로 검증하지 않았다.
- Vercel 프로젝트의 `web` Root Directory 설정과 Git 미리보기 배포를 아직 검증하지 않았다.
- 첫 마이그레이션·Edge Function과 두 브라우저 실시간 동기화는 M2 구현 범위다. 현재 빈 앱의 성공은 MVP 기능의 성공을 뜻하지 않는다.
