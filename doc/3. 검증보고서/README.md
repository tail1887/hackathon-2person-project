# 검증보고서

각 마일스톤을 완료로 전환하기 전에 해당 검증보고서를 이 폴더에 작성한다.

## 폴더와 파일명

마일스톤별로 `M1.1_시스템·데이터_정의/`처럼 식별자와 이름을 함께 쓴 폴더를 만들고, 그 안에 검증 이력을 시간순으로 둔다. 첫 보고서는 `v1_검증보고서.md`, 재검증은 `v2_검증보고서.md`처럼 순번을 올린다. 최신 보고서는 해당 마일스톤 폴더에서 가장 높은 버전 번호의 파일이다.

`README.md`, 마일스톤 폴더, 검증보고서는 일반 문서 번호 규칙의 예외다.

## 작성 양식

```md
# M1.1 시스템·데이터 정의 검증보고서 v1

> 상태: 완료 검증 · YYYY-MM-DD

## 검증 범위

- 이번 마일스톤에서 완료로 판단하는 항목

## 수행 결과

| 확인 항목 | 방법 | 결과 | 근거 |
| --- | --- | --- | --- |
| 예: 데이터 모델·권한 규칙 정의 | 문서 대조 | 통과 | `doc/3_시스템_데이터_정의.md` |

## 미검증 항목과 남은 위험

- 아직 확인하지 못한 항목과 그 이유, 다음 조치

## 완료 확인

- [ ] 관련 의사결정 로그 반영 여부 확인
- [ ] 관련 문서·테스트·화면 확인 근거 기록
- [ ] 변경 사항을 `main`에 커밋하고 푸시
```

보고서를 만든 뒤, [마일스톤 계획](../2_마일스톤_계획.md)의 해당 단계에서 최신 보고서와 필요한 이전 이력으로 연결한다.
