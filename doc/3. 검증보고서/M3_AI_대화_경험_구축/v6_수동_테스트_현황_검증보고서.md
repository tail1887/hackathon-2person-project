# M3 AI 대화 경험 구축 — v6 수동 테스트 현황 검증보고서

> 상태: 대부분 통과 · restricted 안전 흐름 재확인 필요 · 2026-09-21

## 검증 범위

- 프로젝트 소유자의 M3 수동 테스트 완료 보고
- 운영 데이터에 남은 AI 심판·개인 형세·AI 문철 상태
- M3 완료 기준과의 대조

## 수행 결과

| 완료 기준·시나리오 | 결과 | 근거 |
| --- | --- | --- |
| normal AI 심판 결과 생성 | 통과 | 운영 `ai_analyses`에 `message_mediation / ready / normal` 2건이 있다. |
| 초안 수정 뒤 이전 분석 무효화 | 통과 | `message_mediation / stale` 1건이 있다. |
| 개인 형세 파악 | 통과 | `private_position / ready / normal` 3건이 있다. |
| 양측 수락형 AI 문철 | 통과 | `room_review / ready / normal` 1건과 `room_review_requests / ready` 1건이 있다. |
| 문철 실패 취소·새 신청 경계 | 부분 통과 | `room_review_requests / cancelled` 1건이 있다. 재시도 1회 제한과 양측 화면 문구는 프로젝트 소유자의 수동 확인 근거가 필요하다. |
| 위험 입력 restricted 차단 | 미확인 | 운영 `ai_analyses`에 `result_type = restricted` 기록이 없다. 따라서 추천문·원문 전송 차단을 운영에서 판정할 수 없다. |
| 상대·제3 계정 비공개 경계 | 사용자 수동 확인 필요 | 분석 집계만으로는 다른 계정 화면의 비노출을 증명할 수 없다. |

## 판정

M3의 핵심 normal 흐름은 운영에서 실제로 동작한다. 그러나 M3 완료 기준에는 위험 입력을 `restricted`로 처리해 전송 경로를 막는 안전 규칙이 포함된다. 이 기록이 없고, 상대·제3 계정의 비공개 경계도 운영 데이터만으로 증명할 수 없어 **M3 완료 판정은 보류**한다.

## 완료를 위한 최소 확인

1. A가 폭력·협박·자해 위험 표현이 포함된 초안을 `확인`해 `restricted` 결과와 전송 버튼 부재를 확인한다.
2. B와 제3 계정에서 A의 초안·AI 심판 결과·개인 형세가 보이지 않는지 확인한다.
3. 위 두 결과를 프로젝트 소유자가 확인하면 M3를 완료로 전환하고 M4를 시작한다.
