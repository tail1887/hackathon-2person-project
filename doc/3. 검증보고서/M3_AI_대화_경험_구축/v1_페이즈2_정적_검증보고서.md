## 수행 결과

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 브라우저 키 비노출 | 통과 | `ai-judge`만 `OPENAI_API_KEY`를 읽고, 웹 코드는 Supabase Function만 호출 |
| AI 심판 우회 차단 | 통과 | `send_ai_mediated_message`가 분석 소유자·ready/normal 상태·현재 초안 revision·SHA-256 입력 해시·방 멤버·active 상태를 검증 |
| 공용 메시지 최소 공개 | 통과 | `messages`에는 전송 본문·선택·분석 ID만 내부 저장하고, 기존 `room_message_public`은 본문·발신 방 키·순번만 반환 |
| restricted·stale 차단 | 통과 | RPC는 `ready`·`normal` 분석만 허용하며, UI는 restricted에 전송 선택을 표시하지 않음 |
| 정적 앱 검증 | 통과 | `npm run lint`, `npm run build` 통과 |
| DB 스키마 검사 | 통과 | `supabase db lint --local` 통과. 로컬 DB에 새 마이그레이션을 실제 적용하는 검증은 수행하지 않음 |
