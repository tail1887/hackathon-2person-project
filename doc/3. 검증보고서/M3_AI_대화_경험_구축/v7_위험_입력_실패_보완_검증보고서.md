# M3 위험 입력 실패 보완 검증보고서 v7

> 상태: 보완 배포 완료 · 화면 재확인 대기 · 2026-09-21

## 검증 범위

AI 심판에 자해 위험 초안(`나 자살할거야`)을 입력했을 때, 확정 정책인 `restricted` 결과와 전송 차단 대신 일반 AI 실패 안내가 표시된 사례를 확인하고 보완한다.

## 수행한 확인과 결과

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 위험 입력의 기존 동작 | 실패 확인 | 사용자 수동 테스트 화면에 `AI 심판을 준비하지 못했어요`가 표시됨 |
| 원인 분석 | 확인 | 모델 안전 거절은 구조화 JSON 결과가 아닐 수 있는데, 기존 함수는 구조화 결과만 파싱해 일반 실패로 처리함 |
| 서버 제한 분기 | 보완 완료 | `ai-judge`가 자해·폭력·협박·통제 위험 패턴을 감지하면 `ready/restricted` 분석을 즉시 저장·반환하도록 변경 |
| 원격 배포 | 완료 | Supabase `ai-judge` Edge Function 배포 성공 |
| 정적 검증 | 통과 | `git diff --check`, `web`의 `npm run lint` 통과 |

## 보완 결과

위험 초안은 외부 AI 호출을 하지 않고도 `restricted` 결과가 된다. UI는 기존 restricted 시트의 `초안 수정하러 가기`만 표시하며, 원문·추천문 전송 버튼을 만들지 않는다. 이는 위험 입력에 전송·추천·협상 조건 생성을 허용하지 않는 MVP 정책을 그대로 집행한다.

## 미검증 항목과 남은 위험

배포 뒤 실제 브라우저에서 같은 입력을 다시 확인해, 일반 실패 안내가 아닌 restricted 시트와 전송 버튼 부재가 표시되는지 확인해야 한다. 상대·제3 계정의 비공개 경계 확인도 M3 완료 전 남아 있다.
