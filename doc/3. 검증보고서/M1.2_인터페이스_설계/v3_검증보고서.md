## 발견 항목

### P01. `restricted` 화면이 확정 문구·행동 범위를 벗어난다

- **관찰:** 목업의 `restricted` 시트에는 `심한 감정적 모욕/위험 표현`이라는 추가 사유 문구와 사용자가 결과를 `Normal`/`Restricted`로 바꾸는 테스트 셀렉트가 보인다.
- **기준:** [MVP 명세의 `restricted` 규칙](../../1_MVP_명세.md#33-ai-심판-시트)은 수정·재확인 안내만 표시하고, 추천·재작성·협상 조건을 제공하지 않도록 정한다. [페이즈 1 와이어프레임](../../5.%20인터페이스%20설계/01_화면_흐름과_와이어프레임.md#42-메시지와-ai-심판)은 `restricted` 결과에서 초안 수정만 제공한다.
- **영향:** 테스트용 결과 선택기가 실제 사용자 화면처럼 보이고, 추가 사유 문구가 별도 안전 안내로 해석될 수 있다.
- **권장 보완:** 테스트 분기 선택기는 상단 목업 컨트롤러로 옮기거나 테스트 전용 표시로 분리한다. `restricted` 시트에는 확정 문구와 `초안 수정`만 남긴다.
