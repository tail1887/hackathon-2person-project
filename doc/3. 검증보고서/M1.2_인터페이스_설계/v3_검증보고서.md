## 실제 구현 전 확인 항목

### T01. 테스트 컨트롤을 제품 화면과 분리한다

- **관찰:** 목업의 `restricted` 시트에는 결과를 `Normal`/`Restricted`로 바꾸는 테스트 셀렉트와 설명 문구가 보인다.
- **판정:** 목데이터 기반 검증을 위한 테스트 컨트롤이므로 페이즈 1.5 목업의 정책·화면 결함으로 보지 않는다.
- **후속:** 실제 제품 화면을 구현할 때만 [MVP 명세의 `restricted` 규칙](../../1_MVP_명세.md#33-ai-심판-시트)과 [페이즈 1 와이어프레임](../../5.%20인터페이스%20설계/01_화면_흐름과_와이어프레임.md#42-메시지와-ai-심판)에 맞춰 테스트 UI를 분리한다.
