## 미검증 항목과 남은 위험

- 로컬 파일 브라우저의 자동 새로고침·클릭 조작은 현재 보안 정책으로 실행하지 못했다. 따라서 이번 보고서는 정적 코드·구문·문서 대조 결과다.
- 실제 서비스에서는 `room_review` 기록 조회 권한과 `viewedBy` 갱신을 서버에서 검증해야 한다. 현재 목업의 메모리 상태는 페이즈 1.5 범위다.
- 스크립트는 직접 HTML을 여는 목업 실행을 위해 클래식 스크립트로 분리했다. M1.3 실제 프로젝트 뼈대에서는 기능별 모듈·상태 저장소·서버 계약에 맞춰 다시 구체화해야 한다.
- M1.2 전체 완료 판정은 페이즈 2 화면 상태와 페이즈 3 요청·응답·실시간 이벤트 계약 검증까지 남아 있다.
