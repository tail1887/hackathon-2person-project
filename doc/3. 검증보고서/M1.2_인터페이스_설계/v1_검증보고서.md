아래 항목은 검증 중 발견해 보고서 작성 전에 정정했다. 따라서 위 결과 표에는 정정 뒤 기준으로 `충족`으로 표시했다.

| 항목 | 수정 전 근거 | 정정 |

| 조건 0개 합의 뒤 경로 | 11dd9a9 시점 인터페이스 설계 §4.6은 미션 없이 대국방 복귀로 적었고, 같은 시점 최신 대국 수명 규칙은 합의 뒤 종료·지난 대국 보관이었다. | 5a30e22에서 조건 0개도 합의 뒤 종료·보관하도록 통일했다. |
| 로그인 뒤 구조 | 11dd9a9 시점 인터페이스 설계 §2.1은 시작 화면의 단일 대국 카드·별도 목록 없음으로 적었지만, §4.1은 미션과 지난 대국을 함께 둔 메인 구조였다. | 5a30e22에서 로그인 → 메인 → 미션 또는 대국 선택으로 통일했다. |
