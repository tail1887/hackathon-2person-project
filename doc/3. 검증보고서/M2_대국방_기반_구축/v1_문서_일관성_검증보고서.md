## 미검증 항목과 남은 위험

- M2 페이즈 2~5는 아직 구현 전이므로 실제 OAuth, RLS, Edge Function 원자성, 두 브라우저 Realtime 동기화는 검증하지 않았다.
- 기본 아바타의 색상 산출 함수와 빈 표시 이름 대체 규칙은 구현 시 일관되게 정해야 한다. 이는 현재 결정된 범위를 바꾸지 않는 구현 상세이며, 페이즈 2 테스트에서 확인한다.

## 보완 필요 항목과 재검증 조건

- **P01**: 마일스톤 계획의 M1.3 완료·M2 페이즈 1 완료 상태를 현재 기준에 맞춘다. M2의 다음 행동은 페이즈 2 구현으로 표기한다.
- **P02**: M2 완료 기준을 페이즈 2~5의 인증·방/초대 권한·실시간·통합 검증 완료 조건으로 고친다.
- **P03**: 검증보고서 README에 최신 보고서 이력을 연결하고, 과거 목업 링크는 현재 목업 위치로 고치거나 당시 산출물 링크임을 명시한다.
