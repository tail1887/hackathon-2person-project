## 미검증 항목과 남은 위험

- Kakao 앱에는 닉네임 선택 동의를 설정했지만, 실제 Supabase Kakao 인가 요청에는 `profile_image`와 `account_email`도 포함되어 KOE205가 발생한다. Supabase 공식 안내상 `profile_image`·`profile_nickname` 동의 항목을 설정하고, 이메일을 쓰지 않으면 `account_email`을 생략하면서 ‘이메일 없는 사용자 허용’을 켜야 한다. 현재 후자는 켜져 있으나 실제 요청 범위 재확인이 필요하다.
- 이메일·비밀번호 신규 가입, 보존 초대 링크 복귀, 기존 방의 표시 이름 스냅샷은 페이즈 3 방 기능 구현 뒤 재검증한다.
