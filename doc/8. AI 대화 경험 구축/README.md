# M3 AI 대화 경험 구축

> 상태: 완료 · 수동 A/B 검증 완료 · 2026-09-21

M3는 M2의 두 사용자 대국방 위에 필수 AI 심판 전송, 개인 형세 파악, 양측 수락형 AI 문철을 추가한다. OpenAI 호출과 상태 확정은 Supabase Edge Function에서만 수행하고, 브라우저에는 작성자 또는 방 멤버에게 허용된 결과만 보낸다.

## 기준

- [MVP 명세](../1_MVP_명세.md#32-대국방): 필수 AI 심판, 비공개 초안, 형세 파악, AI 문철 규칙
- [시스템·데이터 정의](../3_시스템_데이터_정의.md#31-작성자-개인-기록): 초안·분석·공개 범위·순번 모델
- [화면 상태 설계](../5.%20인터페이스%20설계/02_화면_상태_설계.md#32-초안과-ai-심판): 정상·제한·실패·충돌 상태
- [D2026-09-20-09~10](../1.%20의사결정%20로그/2026-09-20_의사결정_로그.md): 수동 테스트 대체와 M3 AI 실행 기준

## 페이즈 계획

| 페이즈 | 목표 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 01 | 비공개 초안·AI 분석 데이터와 AI 호출 계약 기반 | 작성자 전용 데이터·`private_revision`·구조화 결과 계약이 준비됨 | 완료 |

| 04 | 오류·권한·고정 시나리오 검증 | restricted·실패·수정·권한 차단과 A/B 흐름 검증 | 완료 · 위험 입력 restricted 화면과 A/B 수동 검증 완료 |

## 공통 경계

- 기본 모델은 `gpt-5.6`이며, 변경은 Edge Function 설정 한 곳에서만 한다.
- `OPENAI_API_KEY`는 Supabase Edge Function 비밀값에만 둔다. 브라우저·Next.js 공개 변수·저장소에는 기록하지 않는다.
- AI 심판과 형세 파악은 요청자 전용, AI 문철은 상대 수락 뒤 두 방 멤버 전용이다.
- 모든 감정·의도 해석은 UI에서 `AI의 추정`으로 표시한다. 위험 입력은 `restricted`로만 처리해 전송·추천·협상 생성을 막는다.
- M2 페이즈 5의 자동 통합 검증은 프로젝트 소유자 수동 테스트로 대체했다. M5에서 전체 데모 QA로 다시 확인한다.
