# M3 페이즈 1 — 비공개 데이터와 AI 계약

> 상태: 완료 · 배포·실사용 검증은 페이즈 2와 함께 진행 · 2026-09-20

## 목적

메시지 전송 전에 작성자만 볼 초안·AI 심판 결과를 안전하게 저장하고, 다음 페이즈가 같은 구조화 결과를 사용할 수 있는 서버 계약을 만든다.

## 구현 범위

- `message_drafts`, `user_room_private_states`, `ai_analyses`와 작성자 전용 공개 투영
- 공용 `room_revision`과 분리된 `private_revision`
- 초안 버전·입력 해시·AI 분석 상태·개인 기록 삭제 표식의 서버 저장 경계
- `gpt-5.6` Responses API Structured Outputs의 심판·형세·문철 결과 스키마
- 브라우저에 키·내부 사용자 식별자·다른 사용자의 초안 또는 심판 결과를 보내지 않는 권한 계약

## 제외 범위

- 실제 OpenAI 호출과 AI 심판 시트·전송 버튼 활성화(페이즈 2)
- 개인 형세 파악과 AI 문철의 요청·수락 화면(페이즈 3)
- 무승부 협상·미션(M4)

## 완료 기준

- 비공개 초안·분석이 방의 다른 멤버에게 읽히지 않는다.
- 이후 명령이 초안 `revision`·입력 해시·분석 상태를 검증할 충분한 데이터를 가진다.
- 공용 메시지 조회와 비공개 데이터 조회가 분리된다.

## 구현 결과

- `user_room_private_states`, `message_drafts`, `ai_analyses`와 작성자 전용 공개 투영을 추가했다.
- 기존 `messages`에는 후속 전송 검증을 위한 `send_choice`, `ai_analysis_id`만 추가했고, 전송 UI와 AI 호출은 열지 않았다.
- 분석 유형·가시 범위·상태·초안 버전·입력 해시의 데이터 제약을 서버 스키마에 고정했다.
