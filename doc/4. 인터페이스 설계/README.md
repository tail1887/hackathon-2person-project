# 인터페이스 설계

> 상태: M1.2 진행 중 · 2026-09-18

이 폴더는 [MVP 명세](../1_MVP_명세.md)와 [시스템·데이터 정의](../3_시스템_데이터_정의.md)를 바탕으로, M1.2 인터페이스 설계 작업을 페이즈별로 나누어 관리하는 기준이다. M1.2의 완료 기준과 전체 작업 순서는 [마일스톤 계획](../2_마일스톤_계획.md#M12-인터페이스-설계)을 따른다.

## 문서 구성

- 각 페이즈는 독립된 Markdown 문서 한 개로 관리한다.
- 파일명은 작업 순서와 페이즈명을 사용한다. 예: `01_화면_흐름과_와이어프레임.md`.
- 각 페이즈에서 다루는 화면은 하나의 흐름으로 묶어 기록한다. 다음 페이즈에서 앞선 설계의 범위나 결정을 바꿔야 하면 해당 문서를 함께 갱신한다.

## 페이즈별 설계 양식

각 문서에는 아래 내용을 포함한다.

1. 목적과 진입 조건
2. 화면 구조와 주요 요소
3. 사용자 행동과 상태 전이
4. 로딩·빈 상태·오류·진행 상태
5. 요청·응답·실시간 이벤트 계약
6. 권한·비공개 정보 처리
7. MVP 명세와 시스템 정의의 근거 링크
