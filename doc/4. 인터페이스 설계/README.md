# 인터페이스 설계

> 상태: M1.2 진행 중 · 2026-09-18

이 폴더는 [MVP 명세](../1_MVP_명세.md)와 [시스템·데이터 정의](../3_시스템_데이터_정의.md)를 바탕으로, 고정 데모 시나리오를 페이지별로 설계하는 기준이다. M1.2의 완료 기준과 전체 작업 순서는 [마일스톤 계획](../2_마일스톤_계획.md#M12-인터페이스-설계)을 따른다.

## 문서 구성

- 페이지마다 독립된 Markdown 문서 한 개를 만든다.
- 파일명은 화면 흐름 순서와 페이지명을 사용한다. 예: `01_시작과_대국방_연결.md`.
- 모달·시트처럼 단독 진입 경로와 상태를 가진 화면은 별도 문서로 분리한다.
- 공통 컴포넌트만으로 설명할 수 있는 요소는 해당 페이지 문서에 기록하고, 여러 페이지의 결정이 확정되면 별도 공통 문서로 분리한다.

## 페이지별 설계 양식

각 문서에는 아래 내용을 포함한다.

1. 목적과 진입 조건
2. 화면 구조와 주요 요소
3. 사용자 행동과 상태 전이
4. 로딩·빈 상태·오류·진행 상태
5. 요청·응답·실시간 이벤트 계약
6. 권한·비공개 정보 처리
7. MVP 명세와 시스템 정의의 근거 링크
