# M1.3 페이즈 3 — 프로젝트 뼈대

> 상태: 완료 · 2026-09-19

## 1. 범위와 기준

이 페이즈는 [기술 스택 선정](02_기술_스택_선정.md)의 확정 조합을 실행 가능한 빈 프로젝트로 옮긴다. 실제 로그인·초대·대국방·AI 기능은 M2 이후에 구현한다.

## 2. 생성한 구조

```text
.
├── web/                       # Vercel Root Directory, Next.js App Router 앱
│   ├── src/app/               # 라우트·전역 레이아웃
│   ├── src/contracts/         # 명령 결과와 순번의 공통 TypeScript 형식
│   ├── src/features/          # M2 이후 사용자 기능 모듈
│   └── src/lib/supabase/      # 브라우저 공개 연결값과 향후 클라이언트 경계
├── supabase/
│   ├── migrations/            # Postgres 스키마·RLS·RPC 마이그레이션
│   ├── functions/             # 권한 검증·상태 전이·OpenAI 호출 Edge Functions
│   └── tests/                 # 데이터·권한 검증
├── doc/                       # 기준 문서
└── mockup/                    # M1.2 목업
```

저장소 이름의 공백·한글은 npm 패키지명으로 쓸 수 없으므로 Next.js 앱은 `web/`에 생성했다. Vercel 프로젝트 생성 시 Root Directory도 `web`으로 지정한다.

## 3. 책임 경계

| 위치 | 담당 | 하지 않는 일 |
| --- | --- | --- |
| `web/src/app` | 화면·라우팅·표시용 UI | 권한·상태 전이 확정 |
| `web/src/features` | 기능별 화면 상태·명령 호출 | 다른 기능의 도메인 규칙 보유 |
| `web/src/contracts` | 명령 성공·실패, `roomRevision`·`privateRevision` 공통 형식 | 세부 DB 스키마 확정 |
| `web/src/lib/supabase` | 공개 연결값, 이후 세션·조회 도우미 | service role·OpenAI 키 보관 |
| `supabase/migrations` | 테이블·RLS·RPC의 버전 관리 | 브라우저 의존 코드 |
| `supabase/functions` | 인증·권한·상태 검증, 원자 처리, OpenAI 호출 | 화면 렌더링 |

## 4. 환경 변수와 비밀값

| 위치 | 값 | 공개 여부 |
| --- | --- | --- |
| `web/.env.local` | `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | 브라우저 공개 가능 |
| `supabase/.env.local` 또는 배포 비밀값 | `OPENAI_API_KEY` | 서버 전용 |
| Supabase/Vercel 대시보드 | OAuth 제공자 비밀값, service role | 서버·플랫폼 전용 |

`NEXT_PUBLIC_` 접두사가 있는 값은 브라우저 번들에 포함되므로 공개 연결값만 사용한다. OpenAI API 키는 Edge Function의 비밀값으로만 제공한다. [Next.js 환경 변수](https://nextjs.org/docs/app/guides/environment-variables) · [OpenAI API 인증](https://developers.openai.com/api/reference/overview)

## 5. 실행 방법

```bash
cd web
npm install
cp .env.example .env.local
npm run dev
```

환경 값 없이도 현재 빈 앱은 실행된다. Supabase CLI의 로컬 실행·원격 프로젝트 연결, OAuth 콜백, Edge Function 비밀값, Vercel 미리보기 배포는 페이즈 4에서 실제로 검증한다.

## 6. 제외 범위와 다음 단계

- 네이버 OAuth, 사진 첨부·스토리지·이미지 AI 판별은 만들지 않았다.
- M2에서 인증·초대·대국방의 첫 마이그레이션과 Edge Function을 이 구조에 추가한다.
- 페이즈 4에서는 빈 앱의 로컬 실행과 Vercel 기본 배포를 확인하고 M1.3 검증보고서를 작성한다.
