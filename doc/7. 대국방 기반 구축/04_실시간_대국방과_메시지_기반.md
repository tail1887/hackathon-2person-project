# M2 페이즈 4 — 실시간 대국방과 메시지 기반

> 상태: 예정

## 목적과 범위

방 멤버 두 사람이 대국방에서 같은 공용 상태를 보고, 상대 입장과 공용 메시지 순서를 실시간으로 반영하게 한다.

## 구현 항목

- 대국방 초기 스냅샷: 멤버, 방 상태, 메시지 목록, 최신 `room_revision`
- 초대 대기: 링크·코드·상대 입장 대기, `room.member_joined` 수신 뒤 대국방 전환
- 공용 메시지 저장·조회와 `message.sent` 이벤트의 순서 반영
- Supabase Realtime Broadcast 채널 구독과 멤버 검증
- 마지막 적용 `room_revision` 이후 변경 조회, 단절 시 스냅샷 교체
- 연결 복구 중 마지막 확정 공용 상태 읽기 전용 유지, 30초 실패 시 수동 재시도·메인 복귀

## 메시지 전송 경계

M2는 저장·동기화 기반을 검증하지만 일반 사용자에게 직접 전송 버튼을 노출하지 않는다. M3에서 `message.send`에 최신 AI 분석·원문 해시·원문/추천 선택 검증을 결합해 제품 전송으로 연다. M2의 메시지 이벤트는 통합 테스트·개발용 서버 호출로만 생성한다.

## 테스트와 완료 기준

- 서로 다른 브라우저의 A·B가 같은 방에서 상대 입장과 공용 메시지를 같은 순서로 확인한다.
- 늦게 열린 브라우저·일시 연결 단절 뒤에도 순번 중복·역전 없이 최신 상태로 복구한다.
- 방 밖 사용자와 작성자 전용 데이터는 Broadcast payload에 포함하지 않는다.
