## 2. 목업 위치 및 실행 방법

- **목업 파일**: [`mockup/index.html`](../../mockup/index.html)
- **실행 방법**:
  - 별도 서버 설치 없이 브라우저로 직접 열기:
    ```bash
    open mockup/index.html
    ```
  - 또는 로컬 웹 서버 실행:
    ```bash
    python3 -m http.server 8000
    # 브라우저 접속: http://localhost:8000/mockup/
    ```

### 2.1 목업 컨트롤러 기능

- **사용자 시점 전환**: 상단 툴바의 `민준 (A)` / `서연 (B)` 버튼을 클릭하여 방 생성자 및 초대받은 사용자의 시점을 실시간 전환하여 검증
- **시나리오 셀렉트**: 핵심 시나리오(메인, AI 심판, 무승부 협상 조건/0개/카운터오퍼, 미션 보드)로 즉시 이동
- **리셋 버튼**: 목데이터 및 상태를 초기값으로 복원

## 4. 발견한 화면 문제 및 페이즈 2·3 이관 사항 (`결정 필요`)

1. **상대방 시점의 무승부 제안 수락 상태 동기화**
   - 현 목업에서는 A가 제안을 작성하고 B 시점으로 전환해 수락하는 방식을 검증함. 실제 서비스에서는 SSE/WebSocket 실시간 이벤트를 통해 B의 제안 수락 즉시 A의 대국방이 `closed` 상태로 변경되어야 함 (페이즈 3 계약 이관).
2. **카운터오퍼 수신 후 제안 수정 폼**
   - 카운터오퍼 메시지가 대국방에 도착했을 때, 제안자 A가 이를 클릭하여 기존 작성 중이던 제안 폼을 불러와 수정·재전송하는 데이터 연결 구조 명시 필요 (페이즈 2 화면 상태 이관).
3. **미션 완료 요청 거절/재수행 시 표시**
   - B가 완료 확인 시 `[다시 요청]`을 눌렀을 때, 수행자 A의 화면에서 `재수행 대기` 라벨과 `[재수행 시작]` 버튼이 올바르게 전환됨을 확인함.
