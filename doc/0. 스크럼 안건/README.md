# 스크럼 안건

이 폴더는 스크럼 전에 팀이 함께 검토할 논의 안건을 날짜별로 기록한다. 진행 상황의 개인별 보고서가 아니라, 합의가 필요한 쟁점과 결정 후 반영 대상을 공유하기 위한 공용 기록이다.

제품·기술의 중요한 결정이 확정되면 이 안건 파일에만 남기지 않고 [의사결정 로그](../1.%20의사결정%20로그/README.md)와 관련 기획·명세·시스템 문서에 반영한다.

## 파일 규칙

- 파일명은 `YYYY-MM-DD_스크럼_안건.md` 형식으로 만든다. 예: `2026-09-18_스크럼_안건.md`
- 같은 날짜에 안건이 추가되면 기존 파일에 이어 쓴다.
- 스크럼 안건이 있는 날에만 만든다. 매일 빈 문서를 만들 필요는 없다.

## 작성 양식

```md
# YYYY-MM-DD 스크럼 안건

## 목적

- 이번 스크럼에서 확인할 범위:

## 안건

### 1. [안건 제목]

- 배경:
- 논의할 질문:
- 현재 제안:
- 결정 시 반영 문서:
- 상태: 논의 전 / 논의 중 / 확정 / 보류

## 결정과 후속 반영

- 확정된 결정:
- 반영할 문서:
- 남은 확인:
```
