# 검증보고서

각 마일스톤을 완료로 전환하기 전에 해당 검증보고서를 이 폴더에 작성한다.

## 파일명

`M1.1_검증보고서.md`처럼 마일스톤 식별자를 사용한다. `README.md`와 이 폴더의 보고서는 일반 문서 번호 규칙의 예외다.

## 작성 양식

```md
# M1.1 검증보고서

> 상태: 완료 검증 · YYYY-MM-DD

## 검증 범위

- 이번 마일스톤에서 완료로 판단하는 항목

## 수행 결과

| 확인 항목 | 방법 | 결과 | 근거 |
| --- | --- | --- | --- |
| 예: 데이터 모델·권한 규칙 정의 | 문서 대조 | 통과 | `doc/3_시스템_데이터_정의.md` |

## 미검증 항목과 남은 위험

- 아직 확인하지 못한 항목과 그 이유, 다음 조치

## 완료 확인

- [ ] 관련 의사결정 로그 반영 여부 확인
- [ ] 관련 문서·테스트·화면 확인 근거 기록
- [ ] 변경 사항을 `main`에 커밋하고 푸시
```

보고서를 만든 뒤, [마일스톤 계획](../2_마일스톤_계획.md)의 해당 단계에서 보고서로 연결한다.
