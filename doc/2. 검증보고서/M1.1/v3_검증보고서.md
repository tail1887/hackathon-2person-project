# M1.1 검증보고서 v3

> 상태: 완료 재검증 · 2026-09-18

## 검증 범위

- 대상: [시스템·데이터 정의](../../3_시스템_데이터_정의.md), [MVP 명세](../../1_MVP_명세.md), [M1.1 검증보고서 v2](v2_검증보고서.md) 이후 바뀐 인증·초대 흐름.
- 변경: 인증 전 화면을 로그인·회원가입만으로 제한하고, 초대 코드는 로그인 뒤 시작 화면에서 입력한다. 미로그인 초대 링크는 인증 뒤 원래 링크로 돌아가 수락한다.
- 방법: 미로그인 일반 진입, 미로그인 링크 진입, 로그인 뒤 코드 입장, 링크·코드 수락의 원자적 처리 시나리오를 문서 대조로 검토했다.
- 판정: **M1.1 완료 유지.** 변경된 인증·초대 흐름은 로그인 필수, 방 정보 비공개, 사용자당 진행 중인 방 1개, 초대 수락의 일괄 처리 규칙과 일치한다. 아래 결과는 설계 문서 검증이며 실제 동작 검증은 아니다.

## 미검증 항목과 남은 위험

- 인증 완료 뒤 원래 초대 링크로 돌아가는 구체 보존 방식, 변조 방지, 로그인 제공자별 콜백 처리 방식은 M1.3 기술 선택 항목이다.
- 실제 인증 제공자 연동, 코드 입력 횟수 제한, 링크 만료·방 정원 초과·진행 중인 다른 방 보유 시의 화면 문구와 동작은 구현 뒤 검증한다.
- 기존 M1.1 항목(P02~P07, R02)의 설계 판정은 이번 인증·초대 변경의 영향을 받지 않는다. 그 근거는 [M1.1 검증보고서 v2](v2_검증보고서.md)를 유지한다.
