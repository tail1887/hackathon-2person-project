# M1.1 검증보고서 v5

> 상태: 완료 재검증 · 2026-09-18

## 검증 범위

- 대상: [기획서](../0_커플들이_집착하는_AI_심판이_되었다_기획서.md), [MVP 명세](../1_MVP_명세.md), [시스템·데이터 정의](../3_시스템_데이터_정의.md), [페이즈 1 와이어프레임](../4.%20인터페이스%20설계/01_화면_흐름과_와이어프레임.md).
- 변경: 공용 AI 문철에서 현재 형세·대화 지속 가능성·감정 과열도 판정을 제거하고, 대화 요약·서로 다른 지점·`AI의 추정`인 바람과 걱정·다음 수 제안을 제공하도록 바꿨다.
- 방법: 기획·화면·AI 분석 저장 구조·권한·고정 시나리오를 문서 대조로 확인했다.
- 판정: **M1.1 완료 유지.** `room_review`의 공용 가시 범위와 동기화 규칙은 유지하면서, 결과 콘텐츠가 관계 상태 판정이 아닌 공동 대화 보드로 일치한다. 아래 결과는 설계 문서 검증이며 실제 동작 검증은 아니다.

## 수행 결과

| 확인 항목 | 방법 | 결과 | 근거 |

| 공용 결과의 네 콘텐츠 | 기획서·MVP 명세·와이어프레임 대조 | 통과 | 대화 요약, 서로 다른 지점, `AI의 추정`인 바람과 걱정, 다음 수가 같은 순서로 정의됨 |
| 판정 표현 제거 | 이전 AI 문철 항목과 새 출력 규칙 대조 | 통과 | 현재 형세·대화 지속 가능성·감정 과열도, 승패·잘잘못·관계 상태 판정을 공용 결과에서 제거함 |
| 추정과 사실의 경계 | 각 콘텐츠의 표현 규칙 대조 | 통과 | 대화 요약은 확정 메시지의 말·사건만 정리하고, 바람·걱정에는 `AI의 추정`을 붙임 |
| 공용 저장·동기화 유지 | `room_review` 데이터 모델·권한·이벤트 대조 | 통과 | `visibility: room`, `room_revision`, `analysis.ready`의 방 공용 수신 규칙을 유지하고 네 결과 필드를 구조화함 |
| 다음 행동 연결 | AI 문철 화면과 무승부 흐름 대조 | 통과 | 다음 수는 질문·작은 약속·잠시 쉬기를 제안하며, 결과 화면에서 무승부 제안으로 이동 가능 |

## 미검증 항목과 남은 위험

- `shared_summary`, `different_points`, `inferred_hopes_and_worries`, `next_moves`의 요청·응답 JSON 형태와 길이 제한은 M1.2 페이즈 3에서 정한다.
- 다음 수를 누른 뒤의 실제 화면 동작은 M1.2 페이즈 2에서 상태와 함께 정한다.
- 실제 두 브라우저에서 같은 공용 결과가 동기화되고, AI가 사실 요약과 추정을 일관되게 구분하는지는 구현 뒤 검증한다.
