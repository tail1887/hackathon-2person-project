# 개발 일지

이 폴더는 날짜별 작업 흐름, 선택의 이유, 검증 결과, 남은 문제와 다음 할 일을 기록한다. 제품·기술의 확정 결정은 반드시 [의사결정 로그](../0_커플들이_집착하는_AI_심판이_되었다_기획서.md#14-의사결정-로그)에도 남긴다.

## 파일 규칙

- 일지는 `YYYY-MM-DD_개발일지.md` 형식으로 만든다. 예: `2026-09-17_개발일지.md`
- 같은 날짜의 작업은 기존 일지에 이어 쓴다.
- 일지가 필요한 날에만 만든다. 매일 빈 문서를 만들 필요는 없다.

## 작성 양식

```md
# YYYY-MM-DD 개발 일지

## 한눈에 보기

- 오늘의 목표:
- 핵심 결과:

## 진행 순서와 결정

### 1. [주제]

- 선택:
- 이유:
- 반영 결과:

### 2. [주제]

- 선택:
- 이유:
- 반영 결과:

## 작업·검증 기록

- 변경한 문서·코드:
- 확인한 결과:

## 남은 문제·다음 할 일

- 남은 문제·주의할 점:
- 다음 할 일:

## 관련 기록

- 의사결정 로그:
- 관련 커밋:
```
