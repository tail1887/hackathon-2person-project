# 커플들이 집착하는 AI 심판이 되었다 — MVP 명세

> 이 문서는 해커톤에서 실제로 구현·시연할 최소 경험의 기준이다. 서비스 전체 방향과 확장 기능은 [기획서](0_커플들이_집착하는_AI_심판이_되었다_기획서.md)를 따른다.
>
> **상태: 팀 확인 완료 · 2026-09-16**

---

## 1. MVP 목표

로그인한 두 사용자가 초대 링크 또는 코드로 하나의 대국방에 연결되어 갈등 메시지를 주고받고, AI 도움을 거쳐 조건부 무승부에 합의한 뒤, 각자에게 생성된 회복 미션을 상호 확인까지 완료한다.

### 데모 성공 조건

다음 흐름을 끊김 없이 시연할 수 있다.

```text
A가 대국방 생성
→ B가 초대 링크/코드로 입장
→ A가 날선 메시지 초안 작성
→ AI 훈수 확인 후 원문 또는 대안 문장 전송
→ AI 문철의 형세 파악
→ A의 조건부 무승부 제안
→ B의 카운터오퍼, A의 수락
→ 개인/공동 미션 생성
→ 수행 완료 및 상대 확인
```

### 범위 원칙

- 한 대국방에는 사용자 두 명만 참여한다.
- 진행 중인 대국은 로그인 계정당 한 개만 지원한다.
- 기한은 오늘 또는 내일만 선택할 수 있다.
- AI는 조언·요약·문장 대안을 제공할 뿐, 누가 옳은지 판결하거나 관계를 대신 결정하지 않는다.

## 2. 사용자와 권한


| 역할       | 할 수 있는 일                          | 볼 수 있는 정보               |
| -------- | --------------------------------- | ----------------------- |
| 로그인 사용자 | 대국방 생성, 초대 수락, 본인 미션 재진입 | 본인이 속한 대국 메시지·합의·미션 |
| 방 생성자    | 대국방 생성, 초대 링크/코드 공유, 메시지·제안·미션 처리 | 본인과 상대의 대국 메시지·합의·미션    |
| 초대받은 사용자 | 초대 링크/코드로 입장, 메시지·제안·미션 처리        | 본인과 방 생성자의 대국 메시지·합의·미션 |
| AI       | 메시지 초안 분석, 대안 문장·형세·미션 문구 생성      | 해당 대국방의 필요한 대화 맥락       |


**권한 원칙:** 대국방 밖의 사용자는 메시지·미션·AI 분석 결과를 볼 수 없다. 한쪽이 제안한 개인 미션은 양쪽이 보지만, 수행 책임은 제안자에게만 있다.

## 3. 화면별 명세



### 3.1 시작·대국방 연결


| 항목    | 명세                             |
| ----- | ------------------------------ |
| 목적    | 두 사용자가 같은 대국방에 입장한다.           |
| 진입    | 로그인 후 앱 첫 화면 또는 초대 링크/코드             |
| 입력    | 카카오·구글·네이버 간편 로그인 또는 이메일·비밀번호 회원가입, 표시 이름, `대국방 만들기` 또는 초대 코드      |
| 출력    | 초대 링크/코드, 상대 입장 상태, 대국방 진입 버튼  |
| 완료 조건 | 두 사람이 대국방에 입장하면 채팅 가능한 상태가 된다. |


**동작 규칙**

1. 대국방 생성과 초대 수락은 로그인한 사용자만 할 수 있다.
2. 방 생성 시 공유 가능한 초대 링크와 6자리 코드를 만든다.
3. 로그인하지 않은 사용자가 링크를 열면 유효한 초대를 보존한 채 로그인·회원가입 화면을 연다.
4. 이메일·비밀번호 회원가입 성공 시에는 자동 로그인하고, 간편 로그인 성공 시에도 같은 인증 세션으로 이어진다.
5. 인증 완료 뒤 서버가 초대 유효성·빈자리를 다시 확인해 자동 수락하고 대국방으로 이동한다. 초대가 만료됐거나 방이 찼다면 입장하지 않고 안내를 표시한다.
6. 상대가 코드 또는 링크로 입장하면 양쪽에 `상대가 입장했습니다` 상태를 표시한다.
7. 이미 두 명이 입장한 방에는 추가 입장을 허용하지 않는다.



### 3.2 대국방


| 항목    | 명세                                            |
| ----- | --------------------------------------------- |
| 목적    | 갈등 대화를 주고받고, AI 개입과 무승부 협상으로 진입한다.            |
| 입력    | 메시지 초안, `확인`, `형세 파악`, `무승부 제안`                |
| 출력    | 시간순 메시지, 상대 입장 상태, 진행 중인 제안·미션 요약             |
| 완료 조건 | 메시지가 양쪽 화면에 같은 순서로 표시되고, AI·협상 기능으로 진입할 수 있다. |


**동작 규칙**

- 사용자는 메시지 초안을 작성한 뒤 `확인`을 누른다. 확인은 항상 AI 심판 시트를 연다.
- AI 심판 결과를 본 뒤에만 `원문 전송` 또는 `추천 메시지 전송`을 선택할 수 있다. 시트를 건너뛰어 바로 전송할 수 없다.
- `형세 파악`은 대국방의 별도 버튼으로 언제든 요청할 수 있다.
- 진행 중인 무승부 제안이 있을 때는 대국방 상단에 상태를 고정 표시한다.



### 3.3 AI 심판 시트


| 항목    | 명세                                            |
| ----- | --------------------------------------------- |
| 목적    | 날선 초안을 더 전달 가능한 문장으로 선택할 수 있게 한다.             |
| 입력    | 작성 중인 초안, 선택 입력인 `내가 진짜 원하는 것`                |
| 출력    | 이 수의 위험, 숨은 감정(추정), 대안 문장 2~3개                |
| 완료 조건 | 사용자가 원문 또는 대안 문장을 골라 대국방에 전송한다. |


**출력 규칙**

- 모든 감정·의도 해석에는 `AI의 추정`을 붙인다.
- 대안 문장은 비난·단정 대신 관찰, 감정, 요청을 포함한다.
- 폭력·협박·통제·자해 위험 표현이 감지되면 추천을 멈추고 안전 안내를 먼저 표시한다.
- 작성 중인 초안은 작성자 계정에 비공개로 저장해 기기를 바꿔도 이어 쓸 수 있다.
- 메시지를 전송한 뒤에는 작성자만 해당 메시지의 `내 초안과 AI 심판 보기`를 펼쳐 원문 초안·선택 입력·AI 심판 결과를 확인할 수 있다. 상대에게는 전송된 메시지 본문만 보인다.



### 3.4 AI 문철 — 형세 파악


| 항목    | 명세                                             |
| ----- | ---------------------------------------------- |
| 목적    | 현재 쟁점과 대화 과열 상태를 보여 주고 다음 행동을 고르게 한다.          |
| 입력    | 최근 대화 맥락, `형세 파악` 요청                           |
| 출력    | 현재 형세, 대화 지속 가능성, 감정 과열도, 확인된 사실·추정된 의도, 짧은 해설 |
| 완료 조건 | 사용자가 대국방으로 돌아가거나 무승부 제안으로 이동한다.                |


**표현 규칙**

- 형세는 `난타전`, `교착`, `회복 가능`처럼 대화 상태로 표현한다.
- 누가 잘못했는지 점수나 승패로 판정하지 않는다.



### 3.5 무승부 협상


| 항목    | 명세                                     |
| ----- | -------------------------------------- |
| 목적    | 대화를 잠시 끝내는 대신, 실행할 회복 조건을 두 사람이 합의한다.  |
| 진입    | 대국방 또는 AI 문철의 `무승부 제안` 버튼              |
| 입력    | 조건 0개 이상, 기한(오늘/내일), 제안·수락·카운터오퍼·계속 대국 |
| 출력    | 현재 제안 조건, 상대 응답, 합의 여부                 |
| 완료 조건 | 양쪽이 같은 조건을 수락하면 합의가 성립하고 미션을 생성한다.     |


**상태 전이**

```text
초안 작성 → 제안됨 → 수락됨 → 합의됨 → 미션 생성
                    ├→ 카운터오퍼됨 → 제안됨
                    └→ 계속 대국 → 종료
```

**동작 규칙**

- 카운터오퍼는 기존 조건을 유지하거나 추가·수정해 다시 제안한다.
- 합의되기 전에는 어떤 미션도 생성하지 않는다.
- `계속 대국`을 선택하면 제안은 종료하고 메시지 대화로 돌아간다.



### 3.6 미션 보드와 상대 확인


| 항목    | 명세                                    |
| ----- | ------------------------------------- |
| 목적    | 합의 조건을 실행 가능한 개인 미션 또는 공동 퀘스트로 전환한다.  |
| 입력    | 완료 처리, 상대 확인, 다시 요청, 미션 포기            |
| 출력    | 미션 소유자, 기한, 진행 상태, 상대 확인 상태           |
| 완료 조건 | 개인 미션은 상대가 확인하고, 공동 퀘스트는 양쪽이 완료 처리한다. |


**생성 규칙**

- `오늘 밥은 내가 사기`처럼 제안자가 약속한 조건은 제안자의 개인 미션이다.
- `같이 산책하기`처럼 양쪽 참여가 필요한 조건은 공동 퀘스트다.
- MVP에서는 텍스트 완료 처리와 상대 확인을 기본으로 한다. 사진 인증은 있으면 데모에서 보여 주는 선택 기능이다.

**상태 전이**

```text
합의됨 → 진행 중 → 완료 요청 → 상대 확인 대기 → 완료
                                  └→ 다시 요청 → 진행 중
```

## 4. MVP 데이터와 상태 목록

시스템 설계 단계에서 아래 항목을 테이블·API·실시간 동기화 단위로 구체화한다.


| 항목     | 최소 필드                      | 핵심 상태                  |
| ------ | -------------------------- | ---------------------- |
| 사용자    | id, 표시 이름, 계정 상태                  | 활성                     |
| 인증 수단 | id, 사용자 id, 제공자, 제공자 식별자 또는 이메일 | 카카오 / 구글 / 네이버 / 이메일·비밀번호 |
| 대국방    | id, 참여자 2명, 초대 코드, 생성 시각   | 상대 대기 / 진행 중           |
| 메시지 초안 | id, 대국방 id, 작성자, 본문, 상태 | 작성 중 / 전송됨 / 버림 |
| 메시지    | id, 대국방 id, 발신자, 본문, 시각    | 전송됨                    |
| AI 분석  | id, 메시지/대국방 id, 종류, 결과     | 생성됨 / 안전 안내            |
| 무승부 제안 | id, 제안자, 조건 목록, 기한         | 제안됨 / 카운터오퍼 / 합의됨 / 종료 |
| 미션     | id, 제안 id, 소유자/참여자, 내용, 기한 | 진행 중 / 확인 대기 / 완료 / 포기 |

## 5. 이번 MVP에서 하지 않는 것

- AI 대리전
- 여러 대국방과 친구·관계 관리
- 공개 인증 피드와 개인·공용 대국 복기
- 외부 메신저 연동
- 사진 인증의 AI 판별·공개 운영
- 장기 관계 점수, 랭킹, 위치 기반 추천

## 6. 확정된 MVP 구현 결정

아래 결정은 팀 확인을 마쳤으며, 시스템·기술 설계와 구현의 기본 전제로 사용한다.

| 결정 | 확정안 | 이유 | 상태 |
| --- | --- | --- | --- |
| 로그인 방식 | 카카오·구글·네이버 간편 로그인 또는 이메일·비밀번호 회원가입을 필수로 제공 | 오늘·내일 미션의 재진입과 수행·상호 확인 권한을 안정적으로 유지한다. | 확정 |
| 상대 입장 방식 | 초대 링크와 6자리 코드를 함께 제공 | 같은 자리 데모와 원격 테스트 모두 지원한다. | 확정 |
| 메시지 동기화 | 두 브라우저에 즉시 반영되는 실시간 방식 | 대국방의 핵심 경험을 보장한다. | 확정 |

## 7. 인수 기준 체크리스트

- [ ] 초대 링크 또는 코드로 두 사용자가 같은 대국방에 입장한다.
- [ ] 두 화면에서 메시지와 협상 상태가 일관되게 보인다.
- [ ] 초안 메시지에서 `확인`을 누르면 AI 심판이 반드시 열리고, 원문 또는 추천 메시지만 전송할 수 있다.
- [ ] 전송된 메시지의 초안과 AI 심판 결과는 작성자만 펼쳐 볼 수 있고, 상대에게는 전송 본문만 보인다.
- [ ] AI 문철이 쟁점·과열 상태를 `추정`으로 안내하고 무승부 제안으로 연결한다.
- [ ] 한 사용자가 조건과 기한을 넣어 무승부를 제안할 수 있다.
- [ ] 상대가 수락 또는 카운터오퍼를 할 수 있고, 두 사람 수락 전에는 미션이 생성되지 않는다.
- [ ] 합의된 조건이 개인 미션 또는 공동 퀘스트로 생성된다.
- [ ] 완료 요청과 상대 확인을 거쳐 미션을 완료할 수 있다.
- [ ] 위험 표현에서는 일반 AI 추천 대신 안전 안내를 표시한다.
