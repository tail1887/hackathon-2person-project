# M4 무승부 협상·미션 완주

> 상태: 완료 · 2026-09-21

M4는 M3의 공용 대국방 위에서 두 사용자가 조건부 무승부를 협상하고, 합의한 조건을 개인 미션 또는 공동 퀘스트로 끝까지 수행·확인하게 만든다. 협상과 미션의 최종 전이는 Supabase 서버 명령과 Postgres 트랜잭션에서만 확정한다.

## 범위와 제외

### M4에서 구현

- 조건·선택 방식·책임 주체가 있는 무승부 제안, 수락, 카운터오퍼, 계속 대국, 최신 협상 기록
- 수락 시 선택된 조건만 개인 미션 또는 공동 퀘스트로 원자 생성하고 방을 종료
- 개인 미션의 완료 요청·상대 확인·재수행 요청·재시작·포기
- 공동 퀘스트의 각자 완료 체크인·양쪽 완료·포기
- 양측 수락형 미션 수정 제안과 버전 이력

### M4에서 제외

- AI가 협상 조건을 자동으로 생성하거나 확정하는 기능
- 사진 첨부·사진 인증, 알림 푸시, 반복 미션, 기한 알림
- M5 전체 데모·반응형 QA

## 공통 경계

- 활성 협상은 방당 하나이며, 제안자는 보낸 제안을 수정·재발송할 수 없다. 카운터오퍼가 있어야 새 제안 버전을 만들 수 있다.
- 상대의 유효한 조건 선택과 수락 전에는 미션을 만들거나 방을 종료하지 않는다.
- 협상 기록은 현재 또는 최근 협상 한 건만 읽기 전용으로 남긴다. 카운터오퍼는 일반 메시지가 아니라 원 제안에 연결한다.
- 미션은 종료된 대국방과 독립적으로 계속 처리하며, 두 방 멤버만 읽고 변경한다.
- UI는 [D2026-09-21-01](../1.%20의사결정%20로그/2026-09-21_의사결정_로그.md)의 목업 직접 이관 원칙을 따른다.
