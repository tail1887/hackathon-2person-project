# 2026-09-18 스크럼 안건

## 목적

- M1.1 시스템·데이터 정의 재검증에서 드러난 정책 공백을 확인하고, 수정 순서와 미션 협상 경험의 방향을 합의한다.

## 안건

### 1. M1.1 2차 검증과 문서 수정 순서

- 배경: 기존 [M1.1 검증보고서](../검증보고서/M1.1_검증보고서.md)의 P01·P05는 현재 3번 문서에서 해소됐지만, P02·P03·P04·P06·P07은 재논의가 필요하다.
- 논의할 질문: 잔여 문제의 제품 정책을 어떤 내용으로 확정하고, 어떤 순서로 문서에 반영할 것인가?
- 현재 제안: 3번 문서로 쟁점을 확인한 뒤, 중요한 제품 규칙은 의사결정 로그 → 0번 기획서 → 1번 MVP 명세 → 3번 시스템·데이터 정의 순으로 반영하고, 마지막에 2차 검증한다.
- 결정 시 반영 문서: `doc/0_커플들이_집착하는_AI_심판이_되었다_기획서.md`, `doc/1_MVP_명세.md`, `doc/3_시스템_데이터_정의.md`, `doc/검증보고서/M1.1_검증보고서.md`
- 상태: 논의 전

### 2. 무승부 조건의 복수 선택·직접 입력·수행자 지정

- 배경: 현재 문서는 개인 미션의 책임자를 조건 제안자로 자동 지정해, 카운터오퍼에서 조건을 유지하거나 상대에게 수행을 요청하는 경우 책임이 모호하다.
- 논의할 질문: AI 추천 조건을 복수 선택하게 할지, 선택한 조건의 문구를 어떻게 수정·삭제·직접 추가하게 할지, 각 조건의 수행자를 어떤 방식으로 지정할지?
- 현재 제안: AI 추천은 복수 선택하고, 선택한 각 조건은 수정·삭제·직접 추가를 허용한다. 조건마다 수행자를 `나`·`상대`·`함께` 중 선택하며, AI의 수행자 제안은 수정 가능한 기본값으로 둔다. 상대가 조건을 정하게 하는 흐름은 일반 미션보다 카운터오퍼로 다룬다.
- 결정 시 반영 문서: `doc/0_커플들이_집착하는_AI_심판이_되었다_기획서.md`, `doc/1_MVP_명세.md`, `doc/3_시스템_데이터_정의.md`
- 상태: 논의 전

- 확정된 결정: 스크럼 뒤 기록한다.
